What is implemented
- A full active-universe baseline. No 128/411 candidate restriction is introduced.
- Bounded changed input batches (5,000 events / 8 MiB, 5,000 observed symbols).
- Atomic in-memory evaluation/checkpoint, replay dedup, gap rejection, checkpoint hash,
  restart, STOP, admission, late admission, exit and re-entry receipts.
- Actual unchanged buildPriorityPool admission/scoring/ranking/quality/allocation logic.
- Reuse of per-symbol quoteMetrics ONLY when as-of is identical and that symbol's
  complete input dependencies have not changed. A clock change invalidates all metrics.
- Global ranks, group leaders, membership and allocation always rebuilt from full universe.
- Missing candle vs independently verified no-trade diagnostic is separate from trading gates.
  A native proof resolver is required; the tests use an explicit fixture resolver only.

Important dependency finding
quoteMetrics includes quote age, volume event age and projected volume based on time.
buildPriorityPool includes cross-symbol ranks and group leaders; one changed stock can
alter other stocks' ranks/admission. Global allocation also depends on previous state.
Therefore a changed-symbol-only calculation that leaves all siblings/time-dependent
metrics untouched is NOT equivalent. This prototype deliberately recomputes those
dependencies. It does not claim every-minute full-market processing has been removed.

          events:[{resource,symbol,value}],contextChanged?}
Resources: quoteMap,dailyVolumeMap,intradayMap,capitalMap,chipMap,marginChangeMap,
           stockFutureInitialMap,stockGroupContractMap,preopenReferencePriceMap.
Output: admissions/exits and output.rows (canonical original pool rows), published=false,
        formal_entry_authorization=false. This is an OFFLINE normalized interface, not
        a declaration of direct C2 wire compatibility.
GAP: BLOCKED, caller supplies a separately verified complete baseline; no synthetic patch.
