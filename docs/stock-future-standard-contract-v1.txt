Stock futures standard contract policy and read contract v1
Policy: standard-stock-current-then-next-month-v1.
Select the current calendar-month STANDARD stock future while valid; at its native expiry date 13:30 Asia/Taipei switch to the immediately following calendar month. Never jump to a farther quarter, mini, adjusted, highest-volume or lexical-first product. Ambiguity and missing expiry evidence remain explicit gaps.
Classification uses same-day Fugle products, native product code, contractSize and underlyingSymbol, cross-checked against the same catalogue TAIFEX mapping. Products observed later cannot validate a historical run. Monthly suffix is checked against native endDate month plus final year digit; e.g. 106 means October with year digit 6, disambiguated by endDate=2026-10-21. It is not parsed as month 106.
Display v1: classify first, then require raw ticker name == native product name + verified MMY. For standard products, replace the terminal product suffix 期貨 with 期 and append verified MM. Preserve raw names and stock names (including *) separately. Display is Mother Pool derived; not a captured vendor UI name.
Official references: https://developer.fugle.tw/docs/data-futopt/http-api/intraday/products/ ; https://www.taifex.com.tw/cht/2/sTF .
Discovery: anon SELECT v_fugle_daytrade_stock_future_candidate_publications filtered by exact trade_date. Pin catalogue_run_id and revision from one row for every page; published_at identifies late publication, not original observation.
Read: POST get_fugle_daytrade_stock_future_candidates with p_trade_date, p_catalogue_run_id, p_revision, p_offset=0, p_limit<=200. Advance next_offset until null. Total_count and exact unique future_symbol set must match. Never combine revisions.
Candidate fields: underlying_symbol, stock_name, future_symbol, product_code, raw_name, display_name, display_name_rule, display_name_origin, contract_month, expiry_date, contract_size, contract_size_unit, classification, classification_verified, evidence_trade_date, evidence_observed_at, valid_from, valid_until, catalogue_run_id, catalogue_source_hash, catalogue_observed_at, product_source_url, product_source_sha256, raw_product, raw_contract, exclusion_reasons, selection_status, selected, target_month.
Selection status UNIQUE / MULTIPLE / NO_MATCH / MISSING_EVIDENCE. Only selected=true and UNIQUE are candidate mappings; quotes still require independent same-date/native-event freshness and eligibility validation.
Whole candidate set includes excluded products and other months for audit, not extra subscriptions. Existing Writer publishes at most one immutable catalogue snapshot when semantic selection changes, without per-stock calls or per-minute unchanged writes. RPC failure propagates existing Writer backoff. Metadata source errors use 1/2/4/5 minute source cooldown. A stale metadata lock fails closed pending owner inspection.
No historical quotes/strategy/Gate/Telegram/orders/5M changes. Readable schema or isolated tests are not natural trading-session acceptance.
